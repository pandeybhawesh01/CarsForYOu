================================================================================
COMPONENT ARCHITECTURE
================================================================================

VideoCapture Component
├── File: src/features/inspection/components/VideoCapture.tsx
├── Props:
│   ├── label: string (display label)
│   ├── videoUri?: string (existing video)
│   ├── onCapture: (uri: string) => void (callback)
│   ├── isRequired?: boolean
│   └── hint?: string
└── Features:
    ├── "Tap to record" button (when no video)
    ├── "Video Recorded" preview (when video exists)
    ├── "Edit" button (to re-record)
    └── Error handling

CameraModal Component
├── File: src/features/camera/components/CameraModal.tsx
├── Responsibilities:
│   ├── Request camera permissions
│   ├── Initialize camera device (back camera)
│   ├── Render camera preview
│   ├── Handle recording start/stop
│   ├── Manage flash mode
│   └── Display errors
└── Mode: "video" for video recording

CameraService
├── File: src/features/camera/services/CameraService.ts
├── Methods:
│   ├── startRecording(camera, onFinished, onError)
│   ├── stopRecording(camera)
│   └── capturePhoto(camera, options)
└── Uses: react-native-vision-camera v4 API

PermissionService
├── File: src/features/camera/services/PermissionService.ts
└── Handles: Camera and microphone permissions

================================================================================
VIDEO RECORDING FLOW
================================================================================

1. User taps "Tap to record" button
   ↓
2. VideoCapture.handleOpenCamera() called
   ↓
3. CameraModal opens with mode="video"
   ↓
4. Camera permissions requested (if needed)
   ↓
5. Camera preview displays (back camera)
   ↓
6. User taps red button to START recording
   ↓
7. CameraService.startRecording() called
   ↓
8. Video recording in progress...
   ↓
9. User taps stop button to STOP recording
   ↓
10. CameraService.stopRecording() called
    ↓
11. Video file saved to device cache
    ↓
12. onRecordingFinished callback triggered
    ↓
13. Video URI passed back to VideoCapture
    ↓
14. Preview updated to "Video Recorded"
    ↓
15. onCapture(uri) callback to inspection step
    ↓
16. Video URI stored in inspection data

================================================================================
DEBUGGING TIPS
================================================================================

Enable Console Logging:
All camera operations log to console with [CameraService] and [CameraModal] 
prefixes. Watch for:
- [CameraService] Video recorded at: file:///...
- [CameraModal] Starting video recording...
- [CameraModal] Stopping video recording...
- [CameraModal] Camera initialized

Common Issues:
1. Camera won't open
   → Check camera permissions in app settings
   → Ensure device has camera

2. Recording fails
   → Check storage space (need >100MB)
   → Check microphone permissions

3. No audio in video
   → Grant microphone permission
   → Check RECORD_AUDIO permission

4. Video not saved
   → Check file system permissions
   → Ensure sufficient storage

5. Camera freezes
   → Restart app
   → Check device resources
